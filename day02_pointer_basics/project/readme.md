# Day 02 — Memory Inspector

A C project focused on understanding **memory, pointers, stack, heap, and dynamic memory allocation** for Operating Systems.

## Concepts Practiced

* Stack & Heap
* Pointers & Addresses
* `malloc()` / `free()`
* Arrays & Pointer Arithmetic
* Memory Cleanup

## Run

```bash
gcc -Wall -Wextra memory_inspector.c -o memory_inspector
./memory_inspector
```

**Goal:** Build a practical understanding of how C programs use and access memory.
